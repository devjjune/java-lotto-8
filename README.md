# java-lotto-precourse

## 프로젝트 소개

이 프로젝트에서는 간단한 로또 발매기를 구현한다.
입력한 구입 금액만큼 로또를 발행하고, 당첨 번호 및 보너스 번호와 비교하여 총 수익과 수익률을 구한다.

## 학습 목표

- 관련 함수를 묶어 클래스를 만들고, 객체들이 협력하여 하나의 큰 기능을 수행하도록 한다.
- 클래스와 함수에 대한 단위 테스트를 통해 의도한 대로 정확하게 작동하는 영역을 확보한다.
- 2주 차 공통 피드백(디스코드 참고)을 최대한 반영한다.

## 요구사항 및 기능 구현

### 1. 입력

- 로또 구입 금액을 입력받는다.
- 당첨 번호 6개를 입력받는다.
- 보너스 번호 1개를 입력받는다.

### 2. 실행

[로또 발행]

- 로또 발행 개수를 구한다. (로또 발행 개수 = 로또 구입 금액 / 1,000원)
- 로또 1개를 발행할 때마다 중복되지 않는 6개의 숫자를 뽑는다.
- 출력할 발행 내역을 저장한다. (발행 내역 - 로또 수량 및 번호, 번호는 오름차순으로 정렬)

[로또 추첨]

- 입력 받은 당첨 번호 6개를 저장한다.
- 입력 받은 보너스 번호 1개를 저장한다.
- 입력받은 [당첨 번호 + 보너스 번호] 조합과 발행된 로또를 1장씩 비교한다. 당첨 기준과 금액은 아래와 같다.

```
1등: 6개 번호 일치 / 2,000,000,000원
2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
3등: 5개 번호 일치 / 1,500,000원
4등: 4개 번호 일치 / 50,000원
5등: 3개 번호 일치 / 5,000원
```

[당첨 내역 구하기]

- 1-5등까지 각 등수별로 몇 개 나오는지 구한다.
- 그 개수와 가격을 곱해 '수익'을 구한다.
- 구입 금액과 총 수익을 비교햐여 '총 수익률'을 구한다. (총 수익률 = 총 수익 / 구입 금액 * 100, 소수점 둘째 자리에서 반올림)

[게임 종료]

- 당첨 내역을 구한 이후 게임을 종료한다.

### 3. 출력

- 로또 발행 내역을 출력한다.
- 당첨 내역을 출력한다.
- 예외 상황 시 에러 문구를 출력한다. ([ERROR]로 시작)

### 4. 예외 상황

[입력]

- 입력값이 공백인 경우
- 로또 구입 금액이 1,000원 단위의 양의 정수가 아닌 경우
- 당첨 번호에 숫자와 쉼표 이외에 다른 값을 입력한 경우
- 당첨 번호가 쉼표를 기준으로 6개가 아닌 경우
- 당첨 번호가 1-45 사이의 숫자가 아닌 경우
- 보너스 번호가 1-45 사이의 숫자 하나가 아닌 경우
